# 00. 全体像

## 目的

資金50万円で日本株を自動売買し、収益を目指す。

## 進め方

```
Stage A（口座なし）  設計 → 構築 → ヒストリカル検証
                        ↓ 見込みがあれば
Stage B（口座あり）  ペーパートレード3ヶ月 → 実弾（少額から段階的に）
```

**Stage A は証券口座もAPIも不要で着手できる**（データ源は J-Quants 無料と yfinance）。
戦略に見込みがなければ、口座を開く必要すらない。

Stage B で架空資金のペーパートレードを3ヶ月行い、
事前定義した合格基準（07-go-live-criteria.md）で実弾移行を判定する。
**Stage B でも運用資金は入れない。**

詳細は 09-data-sources.md。

## 中核となる設計方針 — レバレッジ1倍固定の信用取引

**建玉総額（買建 + 売建の合計） ≤ 現金残高。**

信用取引を使いながら、使用金額を現物と同じ水準に抑える。
リスクを現物並みに保ったまま、信用取引のメリットだけを取り込む設計。

| 得るもの | 内容 |
|---|---|
| 同一銘柄の当日複数回転 | 現物の差金決済規制（1銘柄1日1回転が上限）を回避 |
| 空売り | 下落局面でも収益機会。相場環境への依存を減らせる |
| 手数料0円・金利0%・貸株料0% | デイトレ信用の条件。実質コストはスリッページのみ |
| オーバーナイトリスクなし | 当日決済。場が閉じている間の暴落に晒されない |

詳細と、この方針が生む新たなリスクは 02-margin-rules.md を参照。

## 対象市場 — 日本株に限定

本プロジェクトは日本株（東証）のみを対象とする。

### 米国株を検討した結果（将来の再検討用に記録）

2026年6月4日に FINRA 規則4210 が改正され、デイトレードの $25,000 最低証拠金規制
（PDTルール）は撤廃された。小資金でも米国株のデイトレードが制度上は可能になっている。

しかし **50万円規模では日本株が明確に有利**：

| | 日本株（eスマート証券・デイトレ信用） | 米国株（IBKR Pro） |
|---|---|---|
| 取引手数料 | **0円** | Fixed $0.005/株・**最低$1/注文**<br>Tiered $0.0035/株・最低$0.35 + 諸費用 |
| 10万円ポジションの往復コスト | **0%** | **0.11〜0.30%** |
| 為替リスク | なし | USD/JPY が年10%規模で変動 |
| 実行環境 | Windows常時起動が必須 | IB Gateway は Linux 可 |
| 市場時間 | 9:00-15:30 JST | 22:30-05:00 JST（深夜・介入不可） |

**IBKR の「最低$1/注文」が決定的。** 1ポジション $660（約10万円）の場合、
$50 の株なら13株で手数料は実額 $0.065 ではなく**最低額の $1 に張り付く**。
往復 $2 = **0.30%**。最低額が効かなくなるには200株以上必要だが、
それは $10,000/ポジション = 口座資金の3倍。
**50万円では最低手数料が構造的に必ず効き、デイトレの利幅0.3〜0.5%の大半を食う。**

さらに、3ヶ月のペーパートレード評価において**為替変動が成績のシグナルをノイズで覆う**。
USD/JPY が3ヶ月で5%動けば戦略の実力が見えなくなる。

### 再検討の条件

- 資金が **$25,000（約380万円）規模に育つ** → IBKR の最低手数料が効かなくなる
- 戦略を**低頻度のスイングに振る** → 往復0.1〜0.3%が相対的に無視できる

`broker/base.py` の抽象インターフェースにより、将来の移行は Broker 実装の追加だけで済む。

> 「米国株の方が低リスク高パフォーマンス」ではない。米国市場は長期的に
> 右肩上がりでロングバイアス戦略に追い風だったが、それは「機会が多い」ことを意味しても
> 「リスクが低い」ことは意味しない。**ボラティリティが高い＝リスクが高い**。

## 目標リターンと現実的な評価

月利5% = 20営業日で5% = **1日平均0.244%（50万円で日次約1,220円）**。
月利10% = 1日平均0.48%。

信用・レバ1倍・手数料0・1日複数回転・空売り可という条件では、
**月利5%は射程に入る**（上級者水準だが非現実的ではない）。
**月利10%は相当困難**（年利換算214%、複利で3年後に600万円超）。

**月利5%を目標、月利10%をストレッチ目標**とし、3ヶ月のペーパートレードで実測する。

> **評価軸はリターンそのものではなくシャープレシオ**（リターン ÷ 変動）に置く。
> リターンだけを追うと、たまたま勝った高リスク手法を選んでしまう。

## 工程

**2段階構成。Stage A は口座もAPIも不要で、今すぐ着手できる**（docs/09-data-sources.md）。

### Stage A — 口座なし・APIなし

データ源は J-Quants 無料（メール登録のみ・証券口座不要）と yfinance。

| Phase | 内容 | 完了条件 |
|---|---|---|
| 0 | 設計ドキュメント | ✅ docs/ が揃い、ブランチに push 済み |
| 1 | データ基盤（J-Quants 日足・銘柄一覧 + yfinance 分足） | 日足と5分足がローカルに蓄積。**実機で yfinance の取得可能期間を実測** |
| 2 | ユニバース構築（Layer 1/2） + バックテストエンジン | 日次で銘柄リストが出力。バイアス検査を通過 |
| 3 | 竹の実装 + ヒストリカル検証 | ウォークフォワード検証を通過、成績レポート |

**ゲート: Stage A の成績で、口座を開く価値があるかを判定する。**
見込みがなければここで戦略を練り直す。**口座開設・API申込・Windows常設のコストを払わずに済む。**

### Stage B — 口座あり・APIあり（**運用資金は入れない**）

| Phase | 内容 | 完了条件 |
|---|---|---|
| 4 | kabuステーションAPIラッパー + ペーパー基盤 + **安全装置16項目** | 全安全装置が動作、reconcile と大引け全決済が通る |
| 5 | **3ヶ月ペーパートレード**（竹） | 実測成績が揃う。**システム障害ゼロ**を確認 |
| 6 | 評価 → 改善 or 実弾移行（少額から段階的に） | 合格基準（07）で判定 |

> **口座開設と入金は別。** 口座開設自体は無料・入金不要で、kabuステーションAPI も無料。
> Stage B は「口座は開くが運用資金50万円は入れない」状態。
> ただし Professional プランの条件に信用口座開設と取引実績があるため、
> 最低1回の実取引（数万円程度）が必要な可能性がある（要確認）。

### Stage A が解いたボトルネック

当初計画では「分足はどこからも取れないので、kabuステーションAPI で
**3ヶ月かけて自前蓄積**してからでないと竹を検証できない」という制約があった。

**yfinance は5分足を過去60日分まとめて取得できるため、待たずに検証を始められる。**
オープニングレンジ・ブレイクアウト（30分レンジ）の検証には5分足で十分。
1分足は直近7日しか遡れないが、日次でローリング回収すれば蓄積できる。

### Stage A の限界（口座なしでは検証できないこと）

| 未検証項目 | 対処 |
|---|---|
| 板情報がない → 約定モデルが粗い | スリッページを**保守的に厚く**見積もる |
| 寄り前気配がない → 選定スコアの2指標が使えない | 前日引け時点の情報だけで選定（docs/09 §5） |
| 売建可能銘柄リストが取れない | 流動性上位で代理。Stage B で実データに差し替え |
| **発注系が未検証**（大引けクローズ・冪等性・reconcile・レバレッジ強制） | **Stage B が必要。** 省くと「システム障害ゼロ」が判定できない |

### 並行して必要な人手のアクション

**Stage A では不要。** 以下は Stage B に入る時点で行う：

- 三菱UFJ eスマート証券の口座開設 + 信用取引口座の開設
- kabuステーションAPI の利用申込（ログイン後画面から設定、書面・捺印不要）
- Professionalプラン条件の充足（信用口座開設 + 取引実績）
- Windows PC でのスリープ無効化・kabuステーション自動起動設定

**Stage A で必要なのは J-Quants の無料登録（メールアドレスのみ）だけ。**

| 2 | 信用取引をレバレッジ1倍で使う | 差金決済規制の回避・空売り・手数料0を、リスクを現物並みに保ったまま得る |

| 6 | 松は竹の実弾稼働後に判断 | レイテンシ勝負で機関投資家に構造的に不利。竹の実績を見てから投資判断する |
| 7 | 完全自動 + キルスイッチ | デイトレは場中の人的介入と相性が悪い。安全装置を厚くして無人運転する |
| 8 | 株価レンジは2段階（通常枠/プレミアム枠） | 2,000円超は集中リスクが増すため、期待リターン優位がある場合のみ採用 |
| 9 | 評価軸はシャープレシオ | リターンだけを追うと、たまたま勝った高リスク手法を選んでしまう |
| 10 | 工程を Stage A/B に分割 | 戦略の見込みが立つまで口座開設・API申込のコストを払わない。見込みがなければ口座は不要 |
| 11 | Stage A のデータ源は J-Quants + yfinance | どちらも証券口座不要。yfinance の5分足60日により、分足の3ヶ月蓄積待ちが不要になった |
| 12 | Stage A の選定は前日引け時点の情報のみ | 寄り前気配が取れないため。Stage B で寄り前気配を追加し、予測力を比較検証する |
| 13 | **竹は板情報をシグナルに使わない** | 板の情報は数秒〜数分で陳腐化し、保有数十分の竹とは時間軸が合わない。板を見る手法ほどレイテンシ勝負になり個人が不利。板は執行と Stage B の品質フィルタでのみ使う（`docs/04` 参照） |
| 14 | 日足は J-Quants を正とし yfinance で直近84日を補完 | Free の12週遅延により、5分足のある期間の日足が取れないため。重複期間で乖離を実測し、Light 課金を数字で判断する |
| 15 | データソースも ABC で抽象化しフォールバック構成に | yfinance は非公式で、仕様変更により数日間データが取れないことがある。単一データソースに依存しない |
| 16 | **配当調整を行わない**（分割のみ調整） | 実測で J-Quants と yfinance の乖離が配当調整の有無だけで説明できた（調整なしで 0.0000%）。基準が違うと日足の継ぎ目に架空の値動きが生まれる。必要なのは実際に約定する価格 |
| 17 | **J-Quants は Free を継続**（Light に課金しない） | 基準を揃えたら乖離が完全にゼロだった。**分割調整は JPX 公式と一致しており品質問題はない**。推測ではなく実測が根拠 |
